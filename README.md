# C++ Solo Practice

A repository for personal C++ practice programs and mini-projects.

## Projects

### 1. Basic Grocery Bill Calculator (`grocery_basic.cpp`)
- **Description:** Takes item prices from the user and calculates the total sum.
- **Concepts:** `cin`, `cout`, `setw`, float arithmetic.

### 2. Smart Grocery Billing System (`bill_calculator_proper.cpp`)
- **Description:** Complete itemized grocery receipt generator featuring dynamic discount tiers based on spend, payment method selection, and aligned table output.
- **Concepts Used:** `if-else if-else` conditional logic, `switch-case` statements, `string` data type, and `iomanip` table formatting (`fixed`, `setprecision`, `setw`).
